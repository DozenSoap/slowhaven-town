# 栖迟小镇 · Slowhaven

[在线游玩](https://dozensoap.github.io/slowhaven-town/) · [公开源码仓库](https://github.com/DozenSoap/slowhaven-town) · [原 Site 入口](https://slowhaven-bingguo-town.bingguo101.chatgpt.site/)

一款浏览器本地运行的生活模拟游戏。默认进入可操控角色的生活模式；最初的观赏与布置模式保留在 `dist/diorama.html`。全部模型、纹理和环境音在本地生成，不依赖外部 CDN、AI 对话或在线存档服务。

## 手机与声音更新

手机界面使用紧凑的日期/金钱信息、可展开的状态条、左下模拟摇杆、右下互动按钮和底部五项菜单；互动卡收起顶部信息和底栏，人物与目标会移到实际露出的画面中；横屏把互动卡放到右侧。背包、地图、邻里、手记、成长和设置使用独立的可滚动阅读面板，标题和关闭按钮固定。长互动卡可以展开，反馈消息显示在卡内；播种、浇水、采集、钓鱼与休息成功后自动回到场景。确认弹窗隐藏前一层面板，内容与按钮分别保留空间。摇杆支持力度、死区，并在松手、取消、离开页面或打开面板时归零。姓名与选择框至少 16px，避免 iOS 输入时自动放大后裁切画面。

色彩改为更明亮的草地、树叶、水面和屋顶，降低场景雾与泛黄遮罩。声音使用独立的音乐、环境和音效通道：慢节奏背景旋律，鸟鸣、虫声、风雨、流水与海浪，以及脚步、开门、种植、浇水、收获、买卖和社交提示。首次交互后启动，可一键静音、分别调音；后台或静音时暂停音频，效果同时发声数量有上限。

## 小镇持续活动修复

居民到达行程地点后，会按各自错开的路线继续散步和短暂停留；室内工作人员会在柜台等可行走区域活动，位置由保存的时间与身份确定，绘制和互动共用同一坐标。原有 schema 2 人生、背包和关系无需重建。夜间休息、雨雪避雨、工作和赴约仍由原有日程控制。

生活时钟使用固定步长，按实际经过的前台时间推进，不再把低帧率的每帧时间一律截成 0.06 秒。1 FPS、60 FPS 与混合帧率的计时结果一致；单帧最多补 2 秒，避免长时间卡顿后大量补算。后台、菜单和手动暂停不补离线时间。手机可点时钟暂停或继续，菜单会明确显示暂停原因。

农庄、新街、森林和海岸补上合批的树冠、云、蝴蝶、水面与晾衣动态；新增动态绘制每区最多 6 批。省电模式也有走路动作、风与水面动态。进入主菜单时的背景小镇同样会活动。

## 生活模式

- 创建姓名、性别表达、年龄、起始身份、肤色、发色、衣服、发型和配饰。角色在场景中行走，镜子可改变衣服、发色和配饰。
- 风眠农庄、河畔老街、银杏新街、萤光森林、月湾海岸通过路口连通。20 栋功能建筑拥有室内场景、家具和交互；店铺按营业时间开放。
- 播种、浇水、逐日生长和收获；商店购买、收货箱出售、采集、垂钓、吃饭、做汤、读书、创作、工作、诊疗、泡澡与休息。行动有明确的时间、物品、体力或金钱成本，常用奖励设每日上限。
- 32 位居民有身份、年龄、职业、住处、喜好、工作与休息安排、天气响应和偶尔的出游。对玩家记录信任、亲近、送礼、帮忙、赴约和失约；关系可从陌生人发展为朋友，也有成年角色之间的恋爱。
- 每季 14 天，每年 56 天。天气由人生种子和日期确定，读档不会重抽；玩家和居民逐年长大。健康、压力、技能与作息习惯随生活改变。
- 一整天约 16 分钟。面板、弹窗、后台与离线期间暂停自然时间；行动显式推进时间。回家睡觉进入次日，午夜未眠会被送回家并产生疲劳。
- IndexedDB 保存多个独立人生。自动保存、行动后保存、睡眠后保存、最近三次备份、恢复备份、导入与导出；事务和版本号防止另一页面静默覆盖。浏览器清理仍可能移除数据，导出文件可跨浏览器保存。
- 立体模式与省电 2D 模式共用同一套生活规则和存档。3D 不可用时提供省电模式；移动端有模拟摇杆与大号互动按钮。

操作：点击地面或 WASD 行走，E 交互，B 背包，M 地图，R 邻里，J 手记，空格暂停，Esc 关闭面板；3D 中滚轮缩放、右键旋转。

## 架构与性能

采用原生 ES 模块与已本地锁定的 Three.js r180，无构建步骤。`dist/life/simulation.js` 和 `navigation.js` 是不依赖 DOM、React 或 Three.js 的规则与寻路层；`content.js` 提供稳定内容标识；`storage.js` 负责版本校验与事务；`world.js`、`avatar.js` 和 `map-view.js` 负责呈现，`game.js` 连接输入、UI 与规则。`layout.js` 统一计算场景可见区域、3D 投影和室内取景；省电模式的绘制与点选使用同一套平移坐标。

规则按 10 Hz 调度，时钟按游戏分钟推进；画面插值。远处居民只按行程推进，当前地区才绘制。室外和室内按需生成，缓存至多两片场景，淘汰时释放 GPU 资源；静态物体按材质合并，人物按几何体实例合批并使用实例颜色保留不同服饰；寻路只在目的地变化时计算并缓存。画质档位控制像素比和单一阴影光源。

当前是第一版可玩生活模拟，尚未包含婚后家庭、子女、跨代继承、大规模装修或完整职业剧情。社会互动使用本地编写的对话与确定性规则。

## 旧版观赏模式

- 拖动旋转，滚轮缩放，右键拖动平移；触屏支持单指旋转、双指缩放和平移。
- 通过「邻里手记」认识 32 位居民、29 位动物伙伴和 20 处小镇角落；点击建筑、居民、动物和火车，阅读它们的小故事。居民、动物和列车支持跟随观看，还能打招呼、摸猫、喂鱼、敲钟和给风车送风。
- 在「光阴天气」中选择清晨、白昼、黄昏或夜晚，以及晴、雨、雪。
- 在「布置小镇」中添加乔木、松树、樱花树、花丛、向日葵、长椅、小屋和鸟屋；布置保存在当前浏览器，支持逐步撤回。
- 环境声音由 Web Audio 合成，手动开启后播放；「保存此刻」可导出无界面的 PNG。
- 空格暂停，H 隐藏或显示界面，Esc 关闭面板并返回。

## 本地运行

立体模式需要 WebGL 2；省电模式使用 Canvas 2D。存档需要支持 IndexedDB 的现代浏览器。静态资源完整保存在 dist。

```sh
python -m http.server 8080 --directory dist
```

在浏览器访问 http://localhost:8080。

修改与验证：

```sh
npm ci
npm test
```

## 实现

- `dist/people.js`：圆润人物建模、32 位角色的服装和道具。
- `dist/neighborhood.js`：温室、果园、池塘、花田、野餐角、动物造型与日常动作。
- `dist/town.js`：程序化模型、铁路、居民路线、动物与场景动画、放置碰撞。
- `dist/app.js`：镜头、交互、时间天气、持久化、照片和合成声音。
- `dist/style.css`：响应式悬浮界面。
- `dist/vendor/`：Three.js r180、OrbitControls、几何合并工具及原始许可。

性能措施包括按材质合并静态模型、合并列车和云朵部件、限制像素比、对人物、动物与水波按几何体和材质做动态实例合批、共享几何体及材质、限制新增布置数量、单一阴影灯光，以及页面在后台时暂停更新。
